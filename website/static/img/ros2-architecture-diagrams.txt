## 3. Communication Patterns

```
┌─────────────────────────────────────────────────────────┐
│              ROS 2 Communication Patterns               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Publisher-Subscriber Pattern:                          │
│  ┌─────────────┐           ┌─────────────┐              │
│  │   Node A    │──────────▶│   Node B    │              │
│  │             │           │             │              │
│  │ Publisher   │  Topic    │ Subscriber  │              │
│  │ /sensor_data│  /sensor_ │ /sensor_data│              │
│  └─────────────┘  data     └─────────────┘              │
│                                                         │
│  Service-Client Pattern:                                │
│  ┌─────────────┐           ┌─────────────┐              │
│  │   Node C    │◀─────────▶│   Node D    │              │
│  │             │   Service │             │              │
│  │  Client     │   /add_   │  Service    │              │
│  │ /add_two_int│   two_ints│   Server    │              │
│  └─────────────┘           └─────────────┘              │
│                                                         │
│  Action Pattern:                                        │
│  ┌─────────────┐           ┌─────────────┐              │
│  │   Node E    │◀─────────▶│   Node F    │              │
│  │             │   Action  │             │              │
│  │  Action     │   /fibona │  Action     │              │
│  │  Client     │   cci     │   Server    │              │
│  └─────────────┘           └─────────────┘              │
└─────────────────────────────────────────────────────────┘
```
